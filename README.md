# B2B eCommerce - Unifood

B2B eCommerce  is a Next.js-based B2B (Business-to-Business) eCommerce template designed to streamline the procurement process for wholesale buyers. It transforms the traditional, time-consuming ordering process into a fast, efficient, and user-friendly digital experience.

![Unifood](https://github.com/user-attachments/assets/57155689-a756-4222-8af7-134e556acae2)


## Key Features

### 1. Streamlined Order Management
*   **Quick Order Entry:** Fast add-to-cart functionality with a powerful search and filtering system to quickly find products.
*   **Flexible Ordering Modes:** Support for standard orders (products with prices) and custom orders (where price is determined after submission).
*   **Order Tracking:** Real-time status tracking for submitted, processing, dispatched, and delivered orders.
*   **Reorder Functionality:** Quick reordering from order history to save time.

### 2. Company-Based Accounts
*   **Hierarchical Structure:** Support for multiple users within a company, including Admins, Managers, and General Users.
*   **Approval Workflows:** Managers can review and approve orders placed by General Users.
*   **Role-Based Access:** Granular permissions to control user actions and access levels.

### 3. AI-Powered Product Discovery
*   **Semantic Search:** Find products using natural language queries instead of exact keywords.
*   **Intelligent Recommendations:** AI-driven suggestions based on browsing history, orders, and user preferences.
*   **Related Products:** Discover complementary items to increase order value.

### 4. Enhanced Product Catalog
*   **Variant Support:** Products with multiple variations like color, size, and other attributes.
*   **Image Zoom:** High-quality product images with zoom functionality to inspect product details.
*   **Product Comparison:** Compare multiple products side-by-side to make informed purchasing decisions.

### 5. Robust Authentication & Security
*   **Two-Factor Authentication (2FA):** Enhanced security for user accounts via email verification.
*   **SSO Integration:** Single Sign-On capability for seamless access across platforms.
*   **Secure Login:** Social login options (Google, Microsoft, Facebook) for quick and secure authentication.

### 6. Flexible Payment Options
*   **Multiple Payment Methods:** Support for Credit Card and On Account (Invoice) payments.
*   **Saved Cards:** Secure storage of payment information for faster checkout.
*   **Invoice Generation:** Automated invoice creation for On Account payments.

### 7. User Experience Features
*   **Dark/Light Mode:** User preference for interface theme.
*   **Responsive Design:** Optimized for seamless experience across desktop, tablet, and mobile devices.
*   **Quick Notifications:** Real-time alerts for order status updates and important announcements.
*   **Help Center:** Integrated knowledge base and support system for immediate assistance.

## Tech Stack

*   **Framework:** Next.js 14 (App Router)
*   **Language:** TypeScript
*   **Styling:** Tailwind CSS
*   **State Management:** Redux Toolkit + RTK Query
*   **Authentication:** NextAuth.js
*   **Backend:** Laravel 12 + MySQL
*   **Payment:** Stripe Integration
*   **Deployment:** Vercel (Frontend), AWS/Linux (Backend)
